# 嬗变改造提醒 - 需求基线

状态：迭代中，当前版本未达到稳定发布门槛

日期：2026-07-24

## 1. 目标

当玩家在暗黑破坏神 IV 的赫拉迪姆魔盒中选中“嬗变物品”配方时，D4Hub 在魔盒
边缘显示四个固定提醒：

- 威能
- 回火
- 精造
- 打孔

提醒用于让玩家在按下“重塑”前自行检查装备，不读取或判断装备的实际状态。

## 2. 触发规则

- 仅处理已验证的暗黑破坏神 IV 前台客户端画面；
- 识别到右侧配方列表中红色选中的“嬗变物品”区域后显示提醒；
- 不要求目标槽中已有装备，也不要求显示装备悬浮详情；
- 离开嬗变配方、游戏失焦、暂停监测或退出游戏后立即隐藏提醒。

当前实现不再以单个红色区域直接决定显隐。单帧检测必须同时满足：

- 候选区域位于配方列表的归一化位置和尺寸范围内；
- 红色选中行具有稳定的矩形左右边界；
- 上下文存在暗色、中性的相邻配方行，而不是大面积明亮暖色战斗特效；
- 连续 3 次观测均成立后才进入显示状态；进入后允许 1 次漏检，第 2 次连续漏检退出。

失焦、暂停监测、退出游戏和进入 HUD 布局编辑不经过退出滞回，必须立即清空状态并隐藏。

## 3. 显示规则

- 四项横向并排显示，顺序固定为“威能、回火、精造、打孔”；
- 提示条锚定在选中配方左上方、靠近魔盒输入区的位置；
- 提示条保持置顶、非激活、点击穿透，不遮挡目标装备槽、材料或“重塑”按钮；
- 四项使用不同颜色区分，但不显示通过、失败、已完成或未确认状态。
- 候选框在连续帧间做低通平滑，窗口坐标按 4 像素量化，避免截图抖动造成提示条来回移动；
- 提示条始终放在配方列表左侧并留出间隔，不与选中配方行重叠；尺寸按客户端宽度有限缩放，并按 WPF 实际 DPI 换算。

## 4. 非目标

- 不识别威能、回火、精造或孔位的实际状态；
- 不读取装备详情、物品名称、孔位数量或词缀；
- 不自动移动鼠标、点击“重塑”或阻止玩家操作；
- 不读取游戏内存、流量或本地游戏文件；
- 不保存游戏截图或提醒历史。

## 5. 验收标准

1. 普通游戏画面、角色面板和其他配方不显示提醒；
2. 选中“嬗变物品”后显示且只显示“威能、回火、精造、打孔”；
3. 目标槽为空或非空都不影响提醒显示；
4. 提醒不会接收鼠标或键盘输入；
5. 离开嬗变界面、失焦或暂停监测后立即隐藏；
6. 现有角色 HUD、BD 识别、D2Core 导入和离线验证保持通过。

- `transmutation-user-2.png`：698 x 677，SHA-256

原字节副本保存在本地忽略目录 `.artifacts/transmutation-positive-v1/`，源文件与副本哈希一致。
两张图内容高度相似，只能视为同一类真实正样本的不同裁切/缩放，不能证明不同 HDR、UI 缩放、
语言或连续运行场景均已稳定。

2026-07-27 从用户提供的 1920 x 1080 录像提取了 17 张普通深坑战斗负样本，保存在
`.artifacts/transmutation-negative-v1/`。旧检测器曾把 `frame-01.png` 以约 0.955 置信度误报；
新增配方列表结构约束后，17 张逐帧结果为 0/17 误报。该结果证明已修复当前已知误报，
不代表对所有职业特效、亮度、HDR 或分辨率完成验收。

## 7. 后续稳定门槛

1. 补充至少 1080p、1440p 各一段连续进入/离开魔盒的正样本录像；
2. 补充非嬗变配方被选中、魔盒列表滚动、窗口化和不同 UI 缩放负样本；
3. 分别验证 SDR 与 HDR，HDR 未标定前必须保持未支持，不复用 SDR 阈值；
4. 记录连续帧进入耗时、退出耗时、提示条位置抖动和遮挡结果后再移除“迭代中”状态。
