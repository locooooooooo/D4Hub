# 嬗变改造提醒 - 需求基线

状态：已实施，等待真实游戏画面验收

日期：2026-07-24

## 1. 目标

当玩家在暗黑破坏神 IV 的赫拉迪姆魔盒中选中“嬗变物品”配方时，D4Hub 在魔盒
边缘显示四个固定提醒：

- 威能
- 回火
- 精造
- 打孔

提醒用于让玩家在按下“重塑”前自行检查装备，不读取或判断装备的实际状态。

## 2. 触发规则

- 仅处理已验证的暗黑破坏神 IV 前台客户端画面；
- 识别到右侧配方列表中红色选中的“嬗变物品”区域后显示提醒；
- 不要求目标槽中已有装备，也不要求显示装备悬浮详情；
- 离开嬗变配方、游戏失焦、暂停监测或退出游戏后立即隐藏提醒。

## 3. 显示规则

- 四项横向并排显示，顺序固定为“威能、回火、精造、打孔”；
- 提示条锚定在选中配方左上方、靠近魔盒输入区的位置；
- 提示条保持置顶、非激活、点击穿透，不遮挡目标装备槽、材料或“重塑”按钮；
- 四项使用不同颜色区分，但不显示通过、失败、已完成或未确认状态。

## 4. 非目标

- 不识别威能、回火、精造或孔位的实际状态；
- 不读取装备详情、物品名称、孔位数量或词缀；
- 不自动移动鼠标、点击“重塑”或阻止玩家操作；
- 不读取游戏内存、流量或本地游戏文件；
- 不保存游戏截图或提醒历史。

## 5. 验收标准

1. 普通游戏画面、角色面板和其他配方不显示提醒；
2. 选中“嬗变物品”后显示且只显示“威能、回火、精造、打孔”；
3. 目标槽为空或非空都不影响提醒显示；
4. 提醒不会接收鼠标或键盘输入；
5. 离开嬗变界面、失焦或暂停监测后立即隐藏；
6. 现有角色 HUD、BD 识别、D2Core 导入和离线验证保持通过。
