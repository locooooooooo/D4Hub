# D4Hub 1.0.6

## 战利品过滤器

- 新增死灵法师、圣骑士和术士的 5 条公开 d2core 过滤器。
- 过滤器目录扩展到 18 条，覆盖当前支持的 8 个职业。
- 新条目保留 BD、阶段、适用范围、用途、推荐状态和来源更新时间。
- 死灵法师包含召唤终局过滤器；圣骑士包含后期与日常速刷过滤器；术士包含 1-70 开荒与 T12 速刷过滤器。

## 数据来源

- 新增条目均通过 d2core 构筑页面的“复制”按钮逐条读取并核验长度。
- 过滤码进入本地目录前会去除复制按钮附带的空白字符；未保存说明文字或 HTML。

## 验证边界

- 过滤器目录 JSON 可解析，18 条过滤码均通过本地格式校验。
- AcceptanceTests 增加死灵法师、圣骑士、术士和八职业覆盖断言。
- 完整验收覆盖统计 HUD 几何定位与模式切换时的 OCR 排除区域。
