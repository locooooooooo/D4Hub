# D4Hub 1.0.5

## 战利品过滤器

- 新增德鲁伊、野蛮人、游侠和巫师的公开 d2core 过滤器条目。
- 过滤器集合支持按 BD 名称、阶段、用途和职业搜索筛选。
- 新增推荐优先、最近更新、阶段顺序和名称排序。
- 列表和详情显示 BD、适用范围、开荒/速刷/冲层用途、来源更新时间和推荐状态。
- 本地导入继续兼容原有过滤码格式，并自动补齐基础用途元数据。

## 数据来源

- 新增条目均来自公开 d2core 构筑页面的可见过滤器复制按钮。
- 未显示过滤器的构筑未写入本地目录；重复过滤码未重复收录。

- D4Hub.App Release 构建通过。
- XAML 启动烟测通过。
- 过滤器相关验收通过。
