## Evidence Vocabulary

- **implemented**: the behavior exists in the current working tree.
- **tested**: named local checks passed against that working tree.
- **packaged**: a local artifact was produced; this does not imply source traceability.
- **independently verified**: a verifier other than the implementing worker reproduced the required checks and inspected the diff/evidence.
- **owner accepted**: `human_001` explicitly accepted the named candidate and evidence.
- **committed**: the candidate is frozen in Git at an exact SHA.
- **pushed**: that exact SHA exists on an authorized remote.
- **published**: an authorized release was made available to users.

These states are never inferred from one another.
