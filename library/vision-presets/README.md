# Vision preset reference data

`diablo4companion-baselines.v1.json` is an attributed, data-only reference
catalog. Its profiles are deliberately marked `candidate-only` and are not
automatically loaded by D4Hub.

The numeric brightness thresholds can seed calibration experiments. Tooltip
and paragon measurements are retained for provenance, but they do not define
D4Hub combat, buff, resource, progress, or map regions.

Promote a candidate only after a local fixture receipt establishes the exact
resolution, language, HDR state, UI font size, crop bounds, accepted/rejected
observations, and source frame hashes. Do not add upstream game-derived images
as fixtures or runtime templates.
